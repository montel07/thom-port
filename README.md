##  Overview

I designed and built this portfolio to act as my main digital landing page while pitching to online clients and taking on side jobs. It features a custom dark-themed UI, smooth navigation, and direct access to my creative skill set including web projects, edits, and art.

##  Key Features

* Custom Dark Mode UI: Dark purple aesthetic with a responsive, modern layout.
* Embedded Contact Form: Integrated via Web3Forms for direct inquiries without needing a dedicated backend.
* Navigation & Links: Quick sections for Home, About, Skills, and Contact, alongside direct links to social profiles.

## Tech Stack

* Structure: HTML
* Styling: Custom CSS
* Scripting: JavaScript
* Form Handler: Web3Forms API
* Deployment: Vercel
